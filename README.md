Nutrition Advisor

Nutrition Advisor is an intelligent web application that calculates BMI from height (ft.in) and weight, classifies users as Slim, Fit, or Obese, and generates personalized meal plans with tailored protein, carbs, and fibre. Users can select foods according to their budget, making nutrition guidance practical and personalized.


Features

Accurate BMI calculation from height and weight.
Body classification: Slim, Fit, Obese.
Personalized macronutrient calculation:

Slim: high protein & carbs, minimal fibre
Fit: balanced protein, carbs, and fibre
Obese: medium protein, low carbs, high fibre

Custom meal plan generation based on selected foods.
Budget-friendly food options.
Interactive frontend built with HTML, CSS, JavaScript.
Backend powered by Python Flask and Pandas.



Tech Stack
Backend: Python, Flask
Frontend: HTML, CSS, JavaScript
Data: CSV nutrition dataset handled with Pandas



Requirements
Python 3.10+
Flask
pandas


Install dependencies using:
pip install -r requirements.txt


How to Run Locally

1. Clone the repository:
git clone https://github.com/<your-username>/Nutrition-Advisor.git
cd Nutrition-Advisor

2. Install dependencies:
pip install -r requirements.txt

3. Run the Flask app:
python app.py

4. Open your browser and go to:
http://127.0.0.1:5000

5. Follow the step-by-step form to calculate BMI, select budget, and generate your personalized meal plan.
